CSV is the canonical format for fiscode data. Every entity is a row in a single CSV, discriminated
by the `record_type` column. The flat row shape lives at `packages/csv/src/schema.ts`; adding new
fields means adding new optional columns at the end so old exports still parse.

## Provenance header

Each exported CSV begins with `#`-prefixed comment lines containing app version, export timestamp,
filter (full vs yearly), and a SHA-256 of the data section. Comments are stripped on import via
`Papa.parse({ comments: '#' })`.

```
# fiscode v0.1.0
# exported_at: 2026-06-04T18:00:00Z
# filter: full
# data_sha256: abc123...
record_type,id,...
```

## Record types

Below: one table per `record_type` showing the columns that apply to that record. The common
columns above always apply too; they're omitted here to keep each table focused.

## Import modes

- **overwrite** — snapshot current state into history, truncate tables, load CSV.
- **append** — insert; on PK conflict, append a history entry recording the conflict and skip.
- **restore** — alias for overwrite with confirmation copy emphasizing the snapshot.

## Round-trip guarantee

Snapshot → export full CSV → wipe → import → export full CSV is byte-stable across data rows. The
header line containing the timestamp is masked during equality checks.
